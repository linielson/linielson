## 🔨 What I'm building

### [Ledgerly](https://github.com/linielson/ledgerly)

An open-source **Rails 8.1** project focused on financial-domain modeling, software architecture, and modern engineering practices.

The long-term goal is an invoicing application for freelancers and small agencies, supporting installment payments, refunds, and an immutable double-entry ledger.

**Current engineering work includes:**

- **Domain modeling:** Money and Currency value objects, integer-based monetary calculations, allocation rules, and explicit rounding behavior.
- **Application foundations:** Authentication, session management, and automated RSpec tests.
- **Architecture:** Architecture Decision Records (ADRs) documenting design choices, alternatives, and trade-offs.
- **CI & security:** GitHub Actions workflows for automated tests, linting, and security checks.
- **Code review:** Automated CodeRabbit reviews on pull requests, combined with manual review and testing.
- **Deployment:** Automated deployment through GitHub Actions and Kamal to Oracle Cloud.
